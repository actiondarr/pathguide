# 領路通 PathGuide

專案只維護以下三份最新文件，直接在原檔更新，不再另開交接、對照、階段或Word版本。

| 文件 | 內容 |
|---|---|
| [Frontend](docs/FRONTEND-DESIGN.zh-HK.md) | App現況、操作、室內引導、安裝及真機驗收 |
| [Backend](docs/BACKEND-DESIGN.zh-HK.md) | 帳號、照片、私人訓練、更新、部署及版本回退 |
