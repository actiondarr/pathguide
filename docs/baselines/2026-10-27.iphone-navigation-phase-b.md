# B 階段：iPhone 前景步行導航

日期：2026-10-27。範圍按導航計劃第二版的 B 階段執行。

狀態：功能補強及程式／模擬器驗證完成，B 補強版已透過 USB 安裝並在測試 iPhone 啟動，逐項真機回歸進行中；尚未把 B 階段全部真機項目標為完成。使用者已於本日回報既有版本的基本步行導航正常，沒有提供路段、讀屏及語音等逐項結果。

## 本次交付

- 導航中的下一步、距離、定位狀態及主要操作固定於畫面下方，地圖及詳細內容可獨立捲動。支援兩倍文字及至少 48 點的操作目標；地圖不是必要操作入口。
- 暫停立即更新狀態並停止播報、定位及亮屏要求；繼續從新位置重算。結束需確認，預設操作為「繼續導航」，確認期間不插播路線指示，取消後重播目前有效指示。
- 定位不足時可直接重新定位。定位恢復後提示一次並恢復有效指示；不隨每次距離變更重讀整頁。
- 步驟推進必須由兩個實際位於下一段的定位點支持。單次漂移後回到轉彎前，不能利用先前保留的進度誤推下一步。
- 忽略供應商開頭沒有文字及注意事項的零長度起點標記；純空白指示使用一般前進提示，不推測轉向。短路段省略五十米提前提醒，保留接近提醒；推進後播報新步驟。
- 路線預覽失敗後先重新取得預覽，再由使用者開始導航；文字搜尋及選取結果會收起鍵盤。查詢中可取消，遲到結果不能重新開啟任務。
- 「目前位置」地址查詢最多等待五秒，失敗仍提供定位狀態；暫停／結束後不朗讀遲到地址。接近終點後仍可重播到達提示及查詢位置，需確認入口才結束。
- iOS 原生層拒絕約略定位的逐步導航；導航中精度權限降級時停止定位並還原亮屏狀態。MapKit 沒有搜尋結果與限流分別顯示，不一律視為斷網。

既有的粵語搜尋、VoiceOver／TTS 單一路徑、本機收藏及最近十個地點繼續保留。Android SDK、代理部署及背景導航未在本次擴充。
